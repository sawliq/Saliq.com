## 10 Edge cases (589:2081) — bg surface, y13433
Header: "(07) — Edge cases" / "Designed for when it breaks" / meta "6 covered · 4 known gaps"
Two cards (gap 24, radius xl, padding 32): 
 "Designed and covered" (white card, accent tag; items with ✓ prefix, Body M primary, gap 14):
  ✓ KYC states: pending, approved, failed with re-upload
  ✓ Upload errors for file type and size, shown inline
  ✓ Empty states for listings, NDA, LOI and SPA
  ✓ Typed confirmation before deleting a listing
  ✓ A required reason when rejecting an NDA or LOI
  ✓ Chat states: text, image, document, read receipts
 "Known gaps" (surface bg, DASHED border, outline tag; items with ○ prefix, secondary):
  ○ No offline handling
  ○ No notifications for incoming NDAs, LOIs or messages
  ○ No error state for a failed e-signature
  ○ No bulk actions for sellers
